# Security reporting

Please report suspected vulnerabilities privately so Celestial Electric can assess them without exposing affected systems or customer information.

## How to report

Use the repository's **Security → Report a vulnerability** option when it is available. Otherwise, email **info@celestialelectric.com** with the subject **GitHub security report — repository name**. Start with a short, non-sensitive description and request a secure channel if detailed evidence is needed.

Include the affected public repository or product, version or commit, expected and observed behavior, and a minimal reproduction using synthetic data. Describe potential impact without including live credentials or accessing additional data.

Do not publish vulnerability details in an issue, pull request, discussion, screenshot, or public log. Do not send passwords, tokens, customer records, or recovery codes in the initial email.

## Assessment and disclosure

The responsible maintainer will assess scope and coordinate remediation and disclosure as appropriate. Support and release status are defined by each project's documentation; there is no organization-wide promise that every branch, prototype, or historical release is supported.

This reporting process does not authorize testing against customer systems, production equipment, or infrastructure outside an expressly approved scope. It does not establish a bug bounty or a response-time commitment.
