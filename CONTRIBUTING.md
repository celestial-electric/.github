# Contributing to Celestial Electric

We build tools that connect electrical and energy work with reliable operational records. Contributions should be focused, reproducible, and clear about what has actually been verified.

## Before you start

Read the target repository's README, local instructions, and existing issues or coordination record. Check whether the work is already assigned. For a substantial change, describe the problem and proposed scope before implementation.

Repository-specific templates, authority records, review requirements, and release gates take precedence over these defaults. Keep private project details in their existing private repositories.

## Prepare a change

1. Use a focused branch and keep unrelated edits out of the pull request.
2. Explain the affected capability, current problem, intended behavior, and any assumptions.
3. Include meaningful verification for the change. Record the version tested, results, and any untested or blocked paths; documentation-only edits should receive a content and link review.
4. Describe compatibility, deployment, data, and field implications where relevant. Include rollback or recovery details for consequential changes.
5. Remove secrets, personal data, customer details, and confidential records from examples, logs, screenshots, and attachments before sharing.

## Review and acceptance

Open a pull request and follow the repository's review process. Preserve required checks. Address comments with evidence and request renewed review when the reviewed scope changes materially. Production, access, security, data, or field-impacting work requires a reviewer independent of its author.

AI-assisted work follows the same requirements: the contributor remains responsible for accuracy, confidentiality, rights, and verification. Generated output is not proof that a change works.

## Report problems

Use an existing repository issue template for a reproducible, non-sensitive bug or proposal. Report possible vulnerabilities privately as described in [SECURITY.md](https://github.com/celestial-electric/.github/blob/main/SECURITY.md). For service or business inquiries, see [SUPPORT.md](https://github.com/celestial-electric/.github/blob/main/SUPPORT.md).

Follow our [Code of Conduct](https://github.com/celestial-electric/.github/blob/main/CODE_OF_CONDUCT.md). Each repository retains its own licensing terms; these guidelines grant no additional rights.
