# Getting help

| Need | Where to go |
| --- | --- |
| A reproducible software or documentation problem | The affected repository's issue tracker. Include the version, expected behavior, observed behavior, and redacted reproduction steps. |
| A proposed improvement | The repository's change-request template or existing project discussion. |
| A possible vulnerability or exposed secret | Follow [SECURITY.md](https://github.com/celestial-electric/.github/blob/main/SECURITY.md); use a private reporting route. |
| Electrical services, project inquiries, or business support | [celestialelectric.com](https://www.celestialelectric.com) or [info@celestialelectric.com](mailto:info@celestialelectric.com). |

Keep customer, site, financial, and access information out of public issues. GitHub issues are not an emergency or live field-service channel. Project documentation describes each system's intended use, readiness, and limitations.
