# Celestial Electric — GitHub standards

This repository maintains Celestial Electric's public organization profile and shared contribution guidance.

| File | Purpose |
| --- | --- |
| [Organization profile](profile/README.md) | Public introduction to Celestial Electric. |
| [Repository governance](GOVERNANCE.md) | Repository stewardship, review, evidence, and release responsibilities. |
| [Contributing](CONTRIBUTING.md) | Preparing and submitting a change. |
| [Security](SECURITY.md) | Reporting a possible vulnerability privately. |
| [Support](SUPPORT.md) | Finding the right contact for a question. |
| [Code of conduct](CODE_OF_CONDUCT.md) | Standards for participation. |

GitHub uses supported community files here as defaults when a repository has no corresponding local file. A repository's own instructions, templates, authority records, and release gates continue to apply. This repository does not grant production access, deployment authority, or a software license for another repository.

Changes to these standards should explain their purpose, scope, and effect on existing projects. Technical enforcement is configured separately in GitHub settings; publishing a document does not activate a rule.
